Thor Lite GPU overclock patcher

Raises the GPU top level of an AYN Thor Lite from 670MHz to 905MHz at a lower voltage level. Your files never leave your computer: everything runs in this page.

Use at your own risk. This can cause crashes, extra heat and faster battery drain, and may void your warranty. Not affiliated with AYN. Test with fastboot boot before flashing, keep your original backup in two places, and know how to reach fastboot with the hardware buttons before you flash anything.

Tested only on firmware build eng.ThorLi.20251223.153027 (bootloader unlocked). Other builds may differ; this page stops if the table isn’t what it expects.

1. Dump your boot image (read-only)

You need adb and fastboot (Android platform-tools) and an unlocked bootloader. Download the script, run it on the device through Settings → Run Script as Root, then pull the result.

adb push dump_boot.sh /sdcard/
adb shell cat /sdcard/thor_dump_log.txt
adb pull /sdcard/thor_backup/boot.img .
shasum -a 256 boot.img

The log should show 100663296 bytes. Keep boot.img safe: it is your way back to stock.

2. Patch it

3. Test without installing anything

adb reboot bootloader
fastboot boot boot_gpu905_lv336.img
adb shell cat /sys/class/kgsl/kgsl-3d0/gpu_available_frequencies

The first value should read 905000000. A restart returns to stock. If the screen stays blank or it hangs, hold power for about 15 seconds. Run games and a stress test before going further.

4. Flash permanently (optional)

fastboot getvar current-slot
fastboot flash boot_a boot_gpu905_lv336.img
fastboot reboot

Use the slot that current-slot reports. An AYN firmware update replaces the boot image and removes the overclock.

Back to stock

adb reboot bootloader
fastboot flash boot_a boot.img
fastboot reboot

If Android won’t start, hold the button combo for fastboot (Power + Volume Down on the Thor Lite) and run the last two commands.
