EPIC Thor Lite GPU overclock patcher

Raises the GPU max clock of the AYN Thor Lite from 670MHz to 905MHz. Your files never leave your computer as everything runs in this page.

Use at your own risk. While this has been tested thorougly, this may still potentially cause issues, and may void your warranty. Not affiliated with AYN. Test with fastboot boot before flashing, keep your original backup safe, and know how to reach fastboot with the hardware buttons before you flash anything.

Tested only on firmware build eng.ThorLi.20251223.153027 and the latest update as of 11-8-26 1.0.0.257. Other builds may differ; this page stops if the table isn’t what it expects.

1. Dump your boot image (read-only)

You need adb and fastboot (Android platform-tools) and usb debugging enabled on your device. Download the script, run it on the device through Settings → Run Script as Root, then pull the result.

adb push dump_boot.sh /sdcard/
adb shell cat /sdcard/thor_dump_log.txt
adb pull /sdcard/thor_backup/boot.img .
shasum -a 256 boot.img

The log should show 100663296 bytes. Keep boot.img safe: it is your way back to stock.

2. Patch it

First check that your stock GPU table starts at 670MHz: run adb shell cat /sys/class/kgsl/kgsl-3d0/gpu_available_frequencies. The first value must be 670000000; if it isn’t, this patch isn’t for your chip. “Stepped ladder” builds the 905-780-670-587-490-400-305 table; “Top step only” just swaps 670 for the new top.

3. Test without installing anything

adb reboot bootloader
fastboot boot boot_gpu_ladder.img
adb shell cat /sys/class/kgsl/kgsl-3d0/gpu_available_frequencies

The first value should read 905000000 (in ladder mode the full list is 905000000 780000000 670000000 587000000 490000000 400000000 305000000). Use the file name you downloaded. A restart returns to stock. If the screen stays blank or it hangs, hold power for about 15 seconds. Run games and a stress test before going further.

4. Flash permanently (optional)

fastboot getvar current-slot
fastboot flash boot_a boot_gpu_ladder.img
fastboot reboot

Use the slot that current-slot reports. An AYN firmware update replaces the boot image and removes the overclock.

Back to stock

adb reboot bootloader
fastboot flash boot_a boot.img
fastboot reboot

If Android won’t start, hold the button combo for fastboot (Power + Volume Down on the Thor Lite) and run the last two commands.
